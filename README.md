# PARCEL PANIC — 컨베이어 대작전

벨트, 버퍼와 분류기를 배치해 주문을 제시간에 출고하는 물류 자동화 퍼즐입니다.

[게임 실행](https://hyungminyoon1.github.io/parcel-panic/) · [WEB LAB](https://hyungminyoon1.github.io/web-lab/) · [소스](https://github.com/HyungminYoon1/parcel-panic)

## 게임

- 12개 계약. 1–3개 투입구, 회전된 공장 구조, 2–3개 분류 문자, 12–29개 주문과 설비 정비 구간을 조합합니다.
- 벨트(1원), FIFO 버퍼(3원/3개), R 직진·B 우회전·G 좌회전 분류기(4원). 제한 예산과 주문별 마감을 지켜야 합니다.
- 급행→도착 박자→주문 번호의 결정적 합류. 밀린 화물은 대기하며 삭제되지 않습니다.
- 마우스 드래그 설치, 우클릭 기존 설비 회전, 고스트 배치와 설비 취소/복구. 모바일은 내부 보드 스크롤과 칸 이동 패드를 지원합니다.
- 설계/운행 분리, 일시정지, 한 박자 실행, 1/2/4× 재생과 같은 주문·설비로 리셋.
- 벽/공장 바깥 방향, 잘못된 출고, 마감 초과와 정체의 실제 실패 이유를 표시합니다.

## 조작

팔레트와 방향을 고른 뒤 칸 클릭/드래그. 방향키 선택 칸, Space 설치, R 방향 회전, Delete 철거, Z/Y 취소/복구, P 가동/정지. 운행 리셋 후 설비를 수정합니다.

## 규칙과 기록

박자 시작 점유로 도착 가능 공간을 계산합니다. 같은 박자에 비워질 칸은 아직 빈 칸으로 보지 않습니다. 합류 경쟁은 급행 우선이며 버퍼 내부에서는 도착 순의 앞 화물만 출발합니다. 이동 후 투입구가 비었으면 예정 FIFO 주문 1개를 넣습니다. 정비 시작/끝은 포함하며 기다리는 주문에도 전역 마감이 적용됩니다. 마감 박자까지 도착은 유효하고 다음 박자는 출고 전에 실패 처리합니다.

성공 점수 = max(0, 5000 − 출고 완료 박자×12 − 설비 비용×15 − 누적 화물 대기×2). 실측 대기와 비용을 쓰며 운행 중 설비는 수정할 수 없습니다.

격자 11×9 또는 9×11, 주문 최대 29, 계약당 180박자, 설계 취소/복구 최대 80 상태. 기준 재생 420ms/박자, 1/2/4× 속도, 프레임당 최대 3박자. 설비당 출발 1개, 버퍼 점유 3개.

상태·최고 기록·설정은 현재 페이지 메모리에만 남으며 탭을 닫으면 사라집니다. 계정, 쿠키, 영구 저장, 전체 사용자 순위, 분석 도구, 서버 API 또는 자동 소리 재생은 없습니다. GitHub 호스팅 로그는 앱의 저장 기능과 별개입니다. 외부 폰트/이미지/패키지 없이 직접 그린 Canvas/SVG/CSS 아트를 사용합니다.

## 실행 및 배포

Node.js 22 이상. 외부 패키지를 설치하지 않습니다.

```sh
npm run dev -- 0
npm test
npm run check
```

개발 서버는 127.0.0.1에서 dist만 제공합니다. main의 Pages 워크플로가 테스트와 공개 파일 검사를 통과한 뒤 dist만 배포합니다. 공개 소스는 GitHub Actions입니다.

## 검증

23 model tests: 모든 계약의 실제 출고 ID/시간/비용/점유 보존, 오출고/벽 방향/마감/정체/예산/입력/재현, 급행 마지막 버퍼 슬롯·FIFO와 정비 양 끝 경계.

1/7/12의 일반 팔레트·회전·Canvas 클릭으로 기준 설비를 배치한 뒤 실제 박자 버튼으로 12/24/29개 전체 주문을 69/69/79박자에 출고했습니다. 설비 취소/복구, 실제 시계 가동·정지와 동일 설비 리셋을 확인했습니다.

모델은 12개 모두 검증했고, 브라우저 완주는 1/7/12를 선택하여 확인했습니다. 390/320px에서는 내부 보드 스크롤, 도움말/선택 메뉴와 조작을 검토합니다. 실제 모바일 하드웨어, 모든 브라우저 및 사람의 난도/재미 평가는 별도 확인이 필요합니다. 원격 CI와 실제 공개 결과는 [최신 통합 공개 검증](https://github.com/HyungminYoon1/web-lab/blob/main/docs/verification.md)을 확인하세요.

AI 에이전트와 제작한 독립 단일 플레이 게임입니다. 기존 서비스 코드는 병합하지 않습니다. UTF-8 without BOM / CRLF.
